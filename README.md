## Descripción del proyecto

Este proyecto analiza si existe una relación estadísticamente significativa entre el índice de ocupación hospitalaria y la letalidad en los establecimientos hospitalarios públicos de Chile durante el período 2014–2025.

**Pregunta de investigación:** ¿Existe una relación estadísticamente significativa entre el índice de ocupación hospitalaria y la letalidad en los establecimientos hospitalarios públicos de Chile (2014–2025)?

---

## Fuente de datos

Dataset REM20 (Resumen Estadístico Mensual de Camas y Hospitalización) publicado por el DEIS/MINSAL.  
Disponible en: https://datos.gob.cl

## Instrucciones para reproducir el análisis

1. Clonar el repositorio
2. Instalar las dependencias: `pip install pandas numpy matplotlib seaborn scipy scikit-learn statsmodels`
3. Colocar el archivo CSV en la carpeta `data/`
4. Abrir y ejecutar el notebook `avance2_REM20_final.ipynb` desde el inicio
